# Pixel Store — Simulador de Compras

## Sobre o projeto

A Pixel Store é uma loja fictícia de acessórios tecnológicos desenvolvida como parte de um desafio de programação. O projeto permite visualizar produtos e simular uma compra, calculando o valor total com base nas quantidades escolhidas.

## Produtos

- **Mouse Gamer:** R$ 79,90
- **Headset Pixel:** R$ 129,90
- **Teclado Mecânico:** R$ 159,90

## Tecnologias utilizadas

- HTML5 — estrutura da página.
- CSS3 — aparência e organização visual.
- JavaScript — entrada de quantidades, validações e cálculo da compra.

## Funcionalidades

- Exibição de três produtos com descrições e preços.
- Simulação de compra usando janelas de entrada.
- Cálculo dos subtotais e do total.
- Validação das quantidades informadas.
- Aviso quando nenhum produto é selecionado.
